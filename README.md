# Lampa Remote Config

Плагин для удалённой настройки Lampa между устройствами (ПК ↔ ТВ) по 6-значному коду.  
Работает из **любой сети** (P2P через PeerJS, без своего сервера).

## Возможности

- Показать код на ТВ
- Подключиться с ПК по коду
- Смотреть список плагинов на ТВ
- Добавлять плагин по URL
- Включать / выключать / удалять плагины на ТВ
- Перезагружать Lampa на ТВ

## Установка

1. Залейте репозиторий на GitHub
2. Включите **GitHub Pages** (Settings → Pages → Deploy from branch `main` / `root`)
3. В Lampa (на ПК **и** на ТВ):

```
Настройки → Расширения → Добавить плагин
```

Вставьте ссылку:

```
https://ВАШ_ЮЗЕР.github.io/lampa-remote/remote-config.js
```

(замените `ВАШ_ЮЗЕР` на свой GitHub username)

## Как пользоваться

### На ТВ (хост)

1. Откройте **Настройки → Remote Config**
2. Нажмите **«Стать хостом (ТВ)»**
3. Появится большой 6-значный код — запомните его

### На ПК (контроллер)

1. Откройте **Настройки → Remote Config**
2. В поле **«Подключиться по коду»** введите код с ТВ
3. После успешного соединения откроется экран управления:
   - список плагинов ТВ
   - добавить / вкл / выкл / удалить
   - перезагрузить ТВ

## Примечания

- Код действует, пока хост (ТВ) не отключится и peer-id свободен.
- Если код «занят» — плагин автоматически сгенерирует новый.
- PeerJS использует бесплатный публичный сигнальный сервер (`0.peerjs.com`).
- Для стабильности в сложных сетях (жёсткий NAT) иногда помогает перезапуск хоста.
